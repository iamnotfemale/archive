# archive

종이 한 장, 먹 한 색.
링크를 남기고, 나중에 조용히 꺼내 보는 개인 아카이브.

https://yeoziphab.vercel.app

## 왜 만들었나

읽다 만 글, 언젠가 써먹을 도구, 예쁜 사이트. 대부분 카카오톡 나에게 보내기로 던져 두고 잊습니다. 쌓이면 찾을 수 없고, 찾아도 왜 저장했는지 기억나지 않습니다.

archive는 그 링크들이 갈 곳입니다. 저장은 카톡에 보내는 것만큼 가볍게, 다시 꺼내 볼 때는 한 줄 메모와 태그가 그때의 이유를 알려 줍니다.

## 어떻게 쓰나

**남기기.** 페이지 아무 곳에나 링크를 붙여넣으면 됩니다. 카톡 대화를 통째로 붙여넣어도 그 안의 링크만 골라 한꺼번에 남깁니다. 오른쪽 위 `+`를 누르면 "왜 남기나요" 한 줄과 태그를 함께 적을 수 있습니다. 제목, 설명, 썸네일은 알아서 채워집니다.

**둘러보기.** 남긴 것들은 월별로 한 줄씩 놓입니다. 제목, 도메인, 태그, 날짜뿐입니다. 행에 마우스를 올리면 오른쪽 여백에 썸네일과 메모가 떠오르고, 거기서 바로 고치거나 지울 수 있습니다.

**찾기.** `/`를 누르면 검색이 열립니다. 제목, 메모, 도메인, 태그를 한 번에 봅니다. 타이핑할 때마다 목록이 그 자리에서 걸러집니다. 왼쪽 여백의 태그를 누르면 그 태그만 남습니다.

**정리는 나중에.** 태그 없이 남겨도 됩니다. 왼쪽 위에 "정리되지 않은 것 N"이 조용히 세어 두고, 누르면 그것들만 모아 보여 줍니다. 여유 있을 때 붙이면 됩니다.

## 생김새

색은 셋뿐입니다. 종이, 먹, 그리고 옅은 선 하나. 보조 정보는 새 색이 아니라 먹의 농담으로 표현합니다. 서체는 Pretendard 하나, 날짜와 도메인 같은 작은 정보만 세리프로 바꿔 종이 위 캡션처럼 보이게 했습니다. 카드도, 그림자도, 아이콘도 없습니다. 구분은 여백과 가는 선으로만 합니다.

움직임은 눈치채면 기분 좋고 못 알아채도 상관없는 정도로만 두었습니다. `/`가 살짝 기울고, 미리보기가 여백에 스며들고, 저장할 때 글자가 종이에 번지듯 흐려졌다 사라집니다.

## 직접 띄우기

Next.js 앱입니다. 저장소는 Postgres이고, 데이터베이스 없이 실행하면 로컬 JSON 파일에 저장됩니다.

```bash
npm install
npm run dev
```

Vercel에 배포할 때는 Storage에서 Neon(Postgres)을 연결하고, 환경 변수 `ARCHIVE_TOKEN`에 긴 무작위 문자열을 넣습니다. 배포 후 브라우저에서 `/key?t=<그 문자열>`을 한 번 열면 그 브라우저에서만 저장이 되고, 다른 사람은 읽기만 할 수 있습니다.

| 환경 변수 | 설명 |
|---|---|
| `DATABASE_URL` | Postgres 연결 문자열. Neon 연결 시 자동 생성. `STORAGE_URL`처럼 접두어가 붙어도 인식합니다 |
| `ARCHIVE_TOKEN` | 쓰기 열쇠. 비워 두면 누구나 저장할 수 있습니다 (로컬용) |
